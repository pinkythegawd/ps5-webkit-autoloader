# Changelog

All notable changes to this project will be documented in this file.

## [v0.7.0] - 2026-10-15

The MikePinku fork: lower-firmware support is back, the UI is redesigned, and
the PC host is maintained in this repository again.

### Restored umtx2 (FW 1.00–5.50)
* **1.00–5.50 are supported again** via the umtx2 chain (PSFree/umtx2 research
  by idlesauce, abc and the umtx researchers), dropped upstream in v0.6.0. The
  umtx2 page is patched from the pinned upstream commit by
  `patches/umtx2-autoload.patch` (generated by `tools/gen_umtx2_patch.py`,
  applied by `tools/apply_umtx2_patch.sh`): it boots the shared localhost-only
  elfldr, stages `../autoload.elf` one directory up from the page, and runs the
  full chain on load with no interaction.
* The umtx2 page is a multi-file page served from
  `/app/<version>/umtx2/`; it needs no WebKit kernel offsets from the unified
  base and runs entirely offline.

### Three chains, one installer
* **Automatic chain selection by firmware**: 1.00–5.50 → umtx2, 7.00–12.02 →
  Relapse, 9.05 & 11.40 → Poops (Relapse is unsupported there), 12.02+ →
  Relapse. The installer prompt, the homescreen pointer and the PC-host router
  all follow the same table; lone-chain firmwares never prompt.
* **Both standalone chain pages and the umtx2 page are always cached**
  (~14 MB uncompressed), so switching chains later is one storage key change —
  no re-download, no cache invalidation.
* Title ID is now `PINK00001` and the native log prefix is `[PKAL]`, so the
  fork installs alongside an upstream install without colliding.

### Redesigned interface
* **New dark "Pinku" theme** across the installer, both chain pages, the umtx2
  page and the PC-host router: gradient brand mark, firmware/chain chips,
  progress bar with ARIA live status, and a console log panel.
* **English / French toggle** on every page, persisted in `localStorage`.

### PC host maintained here again
* `pc-host/host.py` + `tools/build_host.py` replace remote-loader's host
  builder: the generated `webkit-autoloader-host.py` embeds the **full setup
  docroot** (router, both chain pages, the umtx2 page, `elfldr.elf` and
  `autoload.elf`), spoofs `manuals.playstation.net` over DNS (UDP 53) and
  HTTPS (443) with a build-time self-signed certificate, and needs only the
  Python 3 standard library.
* All text responses are served with `charset=utf-8` (the stock umtx2 page
  lacked a charset declaration and rendered mojibake on the PS5).
* The router page (`index.html`) detects the PS5 firmware from the User-Agent
  and redirects to the right chain, honouring an explicit `?exploit=` choice.

### For developers
* `make test` now runs five offline suites, including `tools/test_umtx2.js`,
  which pins the umtx2 patch markers, the prepared page, the PC-host router's
  firmware table and the host builder placeholders.
* `make dev` stages a complete docroot (all three chains plus the installer
  page) on `127.0.0.1:8123` for browser preview.

## [v0.6.1] - 2026-10-08 (upstream)

* **9.05, 11.40 & 11.60**: Added missing offsets to fix Poops support.
  *(Note: Relapse remains unsupported on 9.05 and 11.40)*

## [v0.6.0] - 2026-10-07 (upstream)

### Unified Architecture & Upstream Remote Loader Base
* **Single Shared Base**: WebKit Autoloader is now built on top of [ps5-webkit-remote-loader](https://github.com/itsPLK/ps5-webkit-remote-loader), unifying the userland exploit runner, ROP primitives, and payload pipeline across both Poops and Relapse.
* **Developer Iteration & Contributions**: Developers looking to experiment with, test, or improve Poops or Relapse can now do so easily in [ps5-webkit-remote-loader](https://github.com/itsPLK/ps5-webkit-remote-loader) by loading payloads over the network (port 9027). Any improvements made in that repo can be contributed upstream to directly benefit both projects.

### Dropped umtx2 (FW <= 5.50)
* **Dropped Legacy umtx2 Support**: Support for firmwares 1.00–5.50 via umtx2 has been dropped in this release. That path was not receiving updates and was blocking development and architectural changes.
* **Future Lower Firmware Support**: Support for lower firmwares may be added back in the future if it is added to [ps5-webkit-remote-loader](https://github.com/itsPLK/ps5-webkit-remote-loader). Contributions to bring lower firmware support to the new unified base are welcome!

### Exploit & Stability Improvements
* **Relapse Stability**: Stability and reliability improvements for the Relapse chain.
